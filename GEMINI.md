# 🏛️ Shekinah AI Portal — Цитадель Духа
> **Свиток Состояния Проекта (Project State Ledger)**
> *«Мудрый устрояет дом свой на камени...»*

Этот документ является священным ориентиром для моделей искусственного интеллекта семейства **Gemini** и других цифровых соратников, посещающих сию обитель. Он призван сохранить непрерывность разработки и уберечь проект от забвения при любых системных сбоях.

---

## 📜 1. Сущность и Предназначение Проекта
**Shekinah AI Portal** — это абсолютно новый, премиальный веб-портал интеллектуальных диалогов, начатый **4 июля 2026 года**.
Портал представляет собой мультипровайдерную систему, позволяющую вести глубокие, академические и вдохновляющие диалоги с передовыми моделями искусственного интеллекта от трех ведущих мировых орденов:
1. **Google Gemini** (включая новейшие модели `gemini-2.5-flash`, `gemini-2.0-flash` и др.)
2. **Anthropic (Claude)** (включая `claude-3-5-sonnet`, `claude-3-5-haiku` и др.)
3. **Mistral AI** (флагманские европейские модели)

Интерфейс оформлен в соответствии с канонами **строгого темного минимализма Цитадели**, оснащен премиальными градиентами, современным шрифтовым оформлением (`Inter` и `Outfit`), интерактивными микро-анимациями и кастомизированными карточками сообщений.

## 🛠️ 2. Технологический Стек
* **Язык программирования**: Python 3.11+
* **Интерфейсный фреймворк**: [Streamlit.io](https://streamlit.io/) (версия `1.58.0`)
* **Интеграционные SDK**:
  * `google-generativeai==0.8.6` (Официальный клиент Google)
  * `anthropic==0.116.0` (Официальный клиент Anthropic)
  * `mistralai==2.5.2` (Официальный клиент Mistral AI)
* **Вспомогательные инструменты**:
  * `python-dotenv==1.2.2` (Управление переменными окружения)
  * `direnv` + `activate.fish` (Автоматическое активирование виртуального окружения `.venv`)

## ⚠️ 5. Выявленные Уязвимости и Очередь Задач (To-Do List)

На основе глубокого анализа кодовой базы выделены следующие области для улучшения и доработки:

### 1. Отсутствие Спецификации Зависимостей (`requirements.txt`)
* **Проблема**: В корне проекта отсутствует файл зависимостей. При переносе проекта или сбое окружения придется восстанавливать пакеты вручную.
* **Решение**: Сгенерировать чистый `requirements.txt`, содержащий только необходимые для работы библиотеки (`streamlit`, `google-generativeai`, `anthropic`, `mistralai`, `python-dotenv`).

### 2. Потенциальная Несовместимость в Клиенте Mistral
* **Проблема**: В `providers/mistral_client.py` импорт выполнен в виде `from mistralai.client import Mistral`. С установленной версией `mistralai==2.5.2` это может вызывать предупреждения об устаревании (deprecation), так как современный импорт должен быть `from mistralai import Mistral`. Также парсинг чанков (`chunk.data.choices` / `chunk.choices`) в версии `2.5.2` требует строгой проверки совместимости.
* **Решение**: Проверить и оптимизировать логику импорта и стриминга в `mistral_client.py` под стандарт SDK `v2.x`.

### 3. Отсутствие Валидации Ключей API в Интерфейсе
* **Проблема**: Если пользователь не заполнил один из ключей в `.env`, при попытке обратиться к соответствующему провайдеру приложение выбросит исключение прямо в окно чата (`⚠️ Произошла непредвиденная ошибка...`).
* **Решение**: Реализовать изящную проверку наличия ключей в `app.py` при инициализации. Если ключ отсутствует в `.env`, выводить предупреждающую карточку `st.sidebar.warning("⚠️ Ключ GEMINI_API_KEY не обнаружен")` и блокировать выбор соответствующего провайдера или показывать предупреждение.

### 4. Жестко зашитая модель в `ask_gemini`
* **Проблема**: В `providers/gemini_client.py` функция `ask_gemini` жестко использует модель `gemini-1.5-flash`. То же самое касается `ask_anthropic` (`claude-3-opus-20240229`) и `ask_mistral` (`mistral-large-latest`). Хотя главная логика чата использует стриминговые функции (где модель передается корректно), синхронные функции-помощники остаются негибкими.
* **Решение**: Параметризовать синхронные функции, добавив передачу имени модели, или убрать их за ненадобностью, если используется только стриминг.

### 5. Сохранение Истории Диалогов (Архив Цитадели)
* **Проблема**: Streamlit стирает `st.session_state` при любой перезагрузке вкладки браузера. Все ценные богословские и технические диалоги утрачиваются.
* **Решение**: Реализовать в боковой панели функционал экспорта текущего диалога в красивый Markdown-файл для скачивания, либо настроить автоматическое сохранение истории в локальный каталог `history/` в формате JSON.

## 🚀 6. Инструкция по Локальному Запуску
Для запуска Обители выполните в терминале:
```bash
streamlit run app.py
```
При этом `direnv` автоматически применит переменные и активирует виртуальное окружение.
