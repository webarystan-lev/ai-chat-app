## 📜 1. Сущность и Предназначение Проекта
**Shekinah AI Portal** — это абсолютно новый, премиальный веб-портал интеллектуальных диалогов, начатый **4 июля 2026 года**.
Портал представляет собой мультипровайдерную систему, позволяющую вести глубокие, академические и вдохновляющие диалоги с передовыми моделями искусственного интеллекта от трех ведущих мировых орденов:
1. **Google Gemini** (включая новейшие модели `gemini-3.5-flash`, `gemini-3-flash-preview` и др.)
2. **Anthropic (Claude)** (включая `claude-3-5-sonnet`, `claude-haiku-4-5` и др.)
3. **Mistral AI** (флагманские европейские модели)

Интерфейс оформлен в соответствии с канонами **строгого темного minimal-дизайна Цитадели**, оснащен премиальными градиентами, современным шрифтовым оформлением (`Inter` и `Outfit`), интерактивными микро-анимациями, скрытыми спойлерами для «размышлений моделей» (thinking) и кастомизированными карточками сообщений.

## 🏛️ 4. Текущее Состояние Разработки (Статус проекта)

### ✅ Что уже реализовано:
1. **Премиальный UI**: Настроен великолепный CSS-стиль, переопределяющий стандартные компоненты Streamlit. Глубокий фон `#0b0f19`, сияющие градиенты, стильные кнопки с ховером, скругленные карточки сообщений и тени.
2. **Мультипровайдерность**: Реализован бесшовный выбор между Google Gemini, Anthropic и Mistral AI в боковой панели.
3. **Динамический и сессионный опрос моделей (Dynamic Model Polling)**: Выбор моделей полностью отвязан от жесткого кода. Приложение опрашивает API провайдеров (`fetch_gemini_models()`, `fetch_anthropic_models()`, `fetch_mistral_models()`) по ключам пользователя, сохраняя списки в сессии (`st.session_state`). Это исключает сетевые задержки при переключениях. При сбое сети или отсутствии ключа срабатывает автоматический бэкап на эталонные списки.
4. **Управление боковой панелью (JS-мост)**: Интегрирован невидимый JavaScript-мост для программного управления сворачиванием (`collapse`) и разворачиванием (`expand`) Sidebar при клике по кастомным кнопкам «Свернуть/Развернуть настройки Ордена».
5. **Надежный и адаптивный скроллинг страниц (Отказоустойчивый Omni-Scroll)**: Плавающие кнопки скроллинга («Вверх/Вниз» в правом углу) и кнопки навигации («К началу/концу диалога» внизу чата) переведены на продвинутый JavaScript-алгоритм. Он обходит CORS-ограничения (`try-catch` на `window.parent`), динамически находит основной контейнер Streamlit (`.main` или `[data-testid="stAppViewContainer"]`) и плавно прокручивает страницу до упора.
6. **Глубокий сброс кэша браузера и сервера**: Кнопка «Сброс и Обновление» очищает системный кэш Streamlit (`st.cache_data`/`st.cache_resource`), очищает `localStorage` и `sessionStorage` браузера через JS и вызывает принудительную перезагрузку страницы (`window.location.reload(true)`).
7. **Потоковое вещание (Streaming)**: Все три клиента поддерживают генерацию ответов в реальном времени с отображением каретки набора текста (`▌`) и красивой подписью-чином модели из словаря `CITADEL_RANKS`.
8. **Гибкие Настройки**: Возможность на лету менять температуру генерации, максимальное количество токенов (до 8192 токенов) и задавать глубокий системный промпт (роль ассистента).
9. **Автоматизация Окружения**: Настроен автозапуск виртуального окружения при переходе в терминале через `direnv`.
10. **Спецификация Зависимостей**: Создан файл `requirements.txt`, включающий `streamlit`, `google-generativeai`, `anthropic`, `mistralai`, `python-dotenv`, `pyperclip` и `convex`.
11. **Интеграция с GitLab**: Настроено слияние независимых истории локальной ветки и GitLab через стратегию `ours`, репозиторий полностью запушен на сервер (коммит `0f43fe1`).
12. **Живой Таймер и Анимация Аватара**: Интегрирован инкрементальный таймер (`time.time()`) размышлений и вещания модели ИИ в секундах, отображаемый в реальном времени. Во время стриминга аватар последнего сообщения ассистента вращается и светится синим неоновым ореолом с помощью динамической CSS-инъекции. По окончании генерации аватар переходит в состояние благообразного покоя, а таймер и размышления аккуратно прячутся в разворачиваемый спойлер `Процесс размышления модели`.
13. **Мультичатовость (In-Memory)**: Реализовано переключение, создание, редактирование названий и удаление диалогов во вкладке "💬 Архивы".
14. **Интеграция Convex DB (Синхронизация в реальном времени)**:
    * Разработан и развернут отказоустойчивый мост `ConvexBridge` с механизмом `Graceful Fallback`.
    * Добавлены авто-синхронизация жизненного цикла чатов (создание, переименование, удаление, изменение параметров генерации) и реактивная запись реплик пользователя и ИИ.
    * Реализовано бесшовное восстановление всей истории из облака при первой инициализации сессии.
    * Сформирован свиток настроек бэкенда Convex в файле `CONVEX_BACKEND.md`.
15. **Валидация API-ключей в интерфейсе**: Реализована динамическая проверка наличия ключей `GEMINI_API_KEY`, `ANTHROPIC_API_KEY` и `MISTRAL_API_KEY` в `.env`. В боковой панели отображается статус орденов (🟢/🔴). При выборе провайдера без ключа выводится предупреждающая карточка, поле ввода чата блокируется (disabled) с понятным разъяснением, предотвращая падения приложения.
16. **Сохранение и Экспорт Свитков (Локальный бэкап)**: Внедрена функция экспорта текущей беседы в красивый структурированный Markdown-файл. Кнопка «📥 Сохранить свиток (Markdown)» размещена во вкладке настроек и позволяет мгновенно скачать весь диалог со всеми репликами, размышлениями и временными метками.

## 🚀 8. Инструкция по Локальному Запуску и Развертыванию в Копии

При переходе в директорию проекта `/home/lev/web-dev/ai-chat-app/` или `/home/lev/ai-chat-app/`:
```bash
# 1. Разрешите direnv развернуть окружение
direnv allow

# 2. Установите зависимости
pip install -r requirements.txt

# 3. Запустите приложение
streamlit run app.py
```
При этом `direnv` автоматически применит переменные и активирует виртуальное окружение.
Если `direnv` не установлен, инициализируйте и активируйте окружение вручную:
```bash
python -m venv .venv
source .venv/bin/activate.fish
pip install -r requirements.txt
streamlit run app.py
```
