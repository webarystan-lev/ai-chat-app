## 🚀 4. Инструкция по Развертыванию Проекта `ai-chat-app`
При инициализации или переходе в копию проекта в `/home/lev/web-dev/ai-chat-app/` необходимо выполнить следующие шаги для настройки окружения:

### Шаг 1. Переход в обитель проекта
```bash
cd /home/lev/web-dev/ai-chat-app
```

### Шаг 2. Активация Direnv и Виртуального Окружения
В проекте настроен файл `.envrc`, содержащий команду `layout python`. 
Выполните команду для разрешения автоматического управления окружением:
```bash
direnv allow
```
*Инструмент `direnv` автоматически инициализирует изолированную среду Python в директории `.direnv` или `.venv` при каждом входе в каталог через терминал.*

**Альтернативный ручной путь (если direnv не установлен):**
```bash
python -m venv .venv
source .venv/bin/activate.fish  # для Fish-shell
# или source .venv/bin/activate для Bash/Zsh
```

### Шаг 3. Установка Зависимостей
Все библиотеки и их точные версии зафиксированы в `requirements.txt`. Установите их в активное окружение:
```bash
pip install -r requirements.txt
```

### Шаг 4. Настройка Секретных Ключей
Создайте или скопируйте локальный файл `.env` в корень проекта со следующим содержимым:
```env
GEMINI_API_KEY=ваш_ключ_google
ANTHROPIC_API_KEY=ваш_ключ_anthropic
MISTRAL_API_KEY=ваш_ключ_mistral
CONVEX_URL=заготовка_под_подключение_convex_db
```
*(Убедитесь, что `.env` внесен в `.gitignore` для предотвращения утечек в публичные репозитории!)*

### Шаг 5. Запуск Приложения
Для локального запуска веб-интерфейса используйте команду:
```bash
streamlit run app.py
```

## 🏛️ 5. Архитектурные Решения и Достижения

Каждый агент должен бережно сохранять и развивать следующие реализованные решения в `app.py`:
1. **Отказоустойчивый Omni-Scroll**: Четыре навигационные кнопки («Вверх», «Вниз» на плавающей панели и «К началу», «К концу диалога» под сообщениями) используют гибридный алгоритм. Они сочетают нативные HTML-якоря (`#top_anchor` / `#bottom_anchor`) и продвинутый JavaScript-код, который через `window.parent` находит основной прокручиваемый контейнер Streamlit (`.main` или `[data-testid="stAppViewContainer"]`) и плавно скроллит страницу, обходя ограничения безопасности CORS.
2. **Сессионный Динамический Опрос Моделей**: Выбор моделей ИИ не зашит жестко на сервере. При выборе провайдера приложение опрашивает официальные API по ключам пользователя (`fetch_gemini_models()`, `fetch_anthropic_models()`, `fetch_mistral_models()`). Результаты кэшируются в сессии (`st.session_state`), предотвращая сетевые задержки при переключениях. При сбое сети или отсутствии ключа срабатывает автоматический бэкап на эталонный список дефолтных моделей.
3. **JS-мост Сворачивания Sidebar**: Для освобождения визуального пространства при чтении длинных ответов интегрирован невидимый JS-мост, который программно эмулирует клик по кнопке закрытия боковой панели Streamlit.
4. **Сброс и Очистка Кэша**: Кнопка «Сброс и Обновление» очищает серверный кэш Streamlit (`st.cache_data`/`st.cache_resource`), очищает `localStorage` и `sessionStorage` в браузере через JS-скрипт и вызывает принудительную перезагрузку страницы.
5. **Мультичатовость и Интеграция Convex DB (Синхронизация в реальном времени)**:
   * **Шаг 1 [ВЫПОЛНЕНО]**: Созданы вкладки в боковой панели (`🏛️ Настройки` и `💬 Архивы`) и реализована локальная In-Memory мультичатовость.
   * **Шаг 2 [ВЫПОЛНЕНО]**: Успешно подключен Python Convex-клиент, библиотека `convex` внесена в `requirements.txt`.
   * **Шаг 3 [ВЫПОЛНЕНО]**: Прописана священная схема бэкенда Convex, включая мутации и запросы (описано в `CONVEX_BACKEND.md`).
   * **Шаг 4 [ВЫПОЛНЕНО]**: Реализован полнофункциональный мост `ConvexBridge` с бесшовной синхронизацией создания, удаления, переименования чатов и записи сообщений пользователя и ассистента в реальном времени.
6. **Динамическая Валидация Ключей и Мягкая Блокировка (Soft-Lock)**: Предотвращает критические ошибки. В боковой панели выводится наглядный статус орденов (🟢/🔴). Если для выбранного провайдера отсутствует API-ключ, поле ввода чата блокируется (disabled) с выводом дружелюбной предупреждающей плашки.
7. **Экспорт Свитков в Markdown**: Возможность в один клик скачать текущую беседу в структурированном Markdown-файле со всеми репликами, системными промптами, скрытыми размышлениями и таймерами генерации.
