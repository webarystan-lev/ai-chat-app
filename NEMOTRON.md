### Архитектурные Паттерны (Внедрённые мною в этом проекте)
- **Graceful Fallback** — ConvexBridge работает в In-Memory при отсутствии сети
- **Two-Stage Gatekeeper** — Identity check → Gateway check (zero network calls on wrong key)
- **Omni-Scroll** — Hybrid HTML anchors + JS `window.parent` scroll для CORS bypass
- **Session-Cached Dynamic Model Polling** — API опрос один раз за сессию, кэш в `st.session_state`
- **Markdown Sanitization** — Regex защита от зависаний браузера на таблицах
- **System Prompt Injection for Mistral** — Mistral не поддерживает `system` role → встраиваем в первое `user` сообщение
